About the diagnostics

The staged cleaning pipeline provides a structured assessment of transcription divergence between HTR outputs and expert-generated ground truth (GT). The diagnostics focus on identifying where transcription error is concentrated and how it manifests structurally, rather than automatically correcting text.

Outputs are intended to support:

  • evaluation of corpus quality
  • identification of high-drift documents
  • analysis of structural and character-level error patterns
  • evidence-based data selection for downstream model refinement

How to use the outputs

  • Open the corpus report to inspect quantitative diagnostics
  • Open the analysis to view interpretation of the findings
  • Consult both documents together for context

The diagnostics form part of a digital humanities workflow designed to preserve transparency between transcription evidence and model development.

Future versions

Additional report versions may be added as the corpus evolves or as pipeline methods are extended.
