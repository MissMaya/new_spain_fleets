NAOMI Corpus Diagnostics

A diagnostic and risk-assessment framework for evaluating HTR transcription quality. The framework aims to provide a multi-dimensional view of transcription-quality. It also scores documents on quality metrics, identifying subsets that provide particularly good downstream machine learning signals as well as those that should be subjected to expert review before being reintroduced into a machine learning pipeline and those that should be considered for outright removal based on their poor quality.
